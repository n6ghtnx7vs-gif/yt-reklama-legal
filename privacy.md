# Privacy Policy

Last updated: November 15, 2026

yt-reklama is a personal tool used only by the owner of one YouTube channel to upload that channel's own videos.

**What data the app accesses.** With the owner's permission, the app uses the YouTube Data API scope `youtube.upload` to upload videos, titles, descriptions and tags to the owner's channel. It does not read, collect or store data about other people.

**How data is stored.** The OAuth credentials are stored as encrypted secrets in the owner's private GitHub repository. Video files and their descriptions are stored in the same repository. No data is sold or shared with third parties.

**Google and YouTube.** The app uses YouTube API Services. By using it you also agree to the [YouTube Terms of Service](https://www.youtube.com/t/terms). See the [Google Privacy Policy](https://policies.google.com/privacy). Access can be revoked at any time at [Google security settings](https://myaccount.google.com/permissions).
